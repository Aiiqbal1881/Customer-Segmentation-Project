# Customer-Segmentation-Project
# Customer Segmentation using K-Means Clustering

## Overview
Customer segmentation is the process of dividing customers into distinct groups based on shared characteristics. This project uses **Machine Learning (ML)** techniques, specifically **K-Means Clustering**, to segment customers based on their purchasing behavior.

## Technologies Used
- **Python**
- **Machine Learning**
- **K-Means Clustering**
- **Matplotlib** (for visualization)
- **Seaborn** (for statistical graphics)

## Dataset
The dataset used for this project contains customer data with features such as **annual income, spending score, and age**. The data is preprocessed and analyzed to extract meaningful insights.

## Installation
To run this project, ensure you have Python installed along with the following libraries:

```bash
pip install numpy pandas matplotlib seaborn scikit-learn
```

## Project Workflow
1. **Data Preprocessing**: Load and clean the dataset.
2. **Exploratory Data Analysis (EDA)**: Use Matplotlib and Seaborn to visualize customer data.
3. **Applying K-Means Clustering**: Implement the algorithm to segment customers.
4. **Optimal Cluster Selection**: Use the **Elbow Method** to determine the best number of clusters.
5. **Visualization**: Plot the clustered data for insights.

## Usage
Run the Python script:

```bash
python customer_segmentation.py
```

## Results
The project segments customers into distinct clusters based on their spending behavior and annual income. These insights help businesses understand their customers better and create targeted marketing strategies.
